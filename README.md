High-Performance C++ Chess Engine
A custom-built chess move generation and evaluation engine focusing on algorithmic efficiency, dynamic memory management, and advanced C++ features.

Tech Stack & Concepts
Language: C/C++
Libraries: Standard Template Library (STL)
Core Concepts: Object-Oriented Design, Pointer Arithmetic, Dynamic Memory Allocation, Graph/Tree Traversal.
Technical Highlights
Developed an optimized board representation for rapid state evaluation.
Implemented robust move generation algorithms handling all edge cases (en passant, castling, promotion).
Utilized dynamic arrays and pointers strictly, avoiding memory leaks through proper allocation/deallocation routines.
Compilation & Execution
Ensure you have g++ or clang++ installed.
Compile the engine: g++ -O3 -std=c++17 -o chessengine main.cpp
Run the executable: ./chessengine
